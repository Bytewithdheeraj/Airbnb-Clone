# Airbnb Clone

A full-stack vacation-rental web application inspired by Airbnb. Browse stays, create and manage listings, book trips, and pay securely with Razorpay.

## Features

- Browse listings and filter by category or destination
- View listing details and map locations
- Create, edit, and delete your own listings
- Upload listing images using Cloudinary
- Sign up and log in with a password or Google OAuth
- Leave reviews on listings
- Book stays and view your trips
- Make and verify payments with Razorpay
- Receive booking confirmation emails

## Tech Stack

- **Backend:** Node.js, Express
- **Views:** EJS, EJS-Mate
- **Database:** MongoDB with Mongoose
- **Authentication:** Passport.js, local authentication, Google OAuth
- **Images:** Cloudinary
- **Payments:** Razorpay
- **Maps and geocoding:** Geoapify
